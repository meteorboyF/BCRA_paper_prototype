This supplement collects the prototype interface screenshots referenced in
the main text (Section ``User Interface and Functional Showcase''). The
audit and transparency views (ledger explorer and audit log) appear in the
main text; the remaining screens are shown here.

The registration screen (Fig.~\ref{fig:s_registration}) collects a
username, email address, password, and role selection before account
creation. The dashboard (Fig.~\ref{fig:s_dashboard}) is the landing page,
presenting the primary navigation cards for case work, documents,
communication, and audit-oriented tasks. The case-management view
(Fig.~\ref{fig:s_case_management}) displays active matters as cards with
case titles, client names, status labels, short descriptions, and a
control for creating a new case.

The document views show the information exposed after a file is selected.
The document-details dialog (Fig.~\ref{fig:s_document_details}) lists the
file name, associated case, owner, content identifier, transaction
identifier, integrity hash, and available actions. The download dialog
(Fig.~\ref{fig:s_document_download}) shows the selected file, access
status, wrapped-key reference, encrypted-file reference, password prompt,
and separate controls for downloading the encrypted object or saving the
decrypted copy.
